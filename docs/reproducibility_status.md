# 当前复现状态

通用工具已在本地示范与 rollout 数据上验证。此次整理没有执行机械臂采集、重新训练或重新评估策略成功率。

## 通用脚本

- 不同阶段的数据质检、执行对比和搬运诊断统一为 `scripts/check.py` 的三个子命令。
- 数据路径、预期 episode 数、延迟和限幅阈值由参数指定；FPS 读取元信息。
- 逐 episode 分析，报告按运行隔离；处理夹爪闭合缺失、短 episode 和 NaN/Inf。
- 回放与 F 位置视频整理共用 LeRobot v3 元信息定位，不再假定只有 `file-000.mp4`。
- 固定位置采集合并为一个入口并支持设备覆盖；Grid5 保留专用采集顺序。
- `scripts/rollout.py` 使用已确认的主评估配置：30 FPS、20 秒 episode、30 秒 reset、100 动作步、10.0 限幅；串口必须通过 `ROBOT_PORT` 指定。25 步消融使用独立显式选项。

完整命令与迁移表见 [脚本使用说明](script_usage.md)。

## 保留的限制

- 工具针对本项目的 SO-101 六关节顺序，wrist_roll 使用最短角差；其他关节排列会被拒绝。
- 夹爪推断假设训练 episode 开头张开，闭合不是抓取成功的证据。
- 运动、跟踪及限幅统计提供离线诊断信息，不是实时控制保护或自动成功判定。
- Grid5 采集仍有固定设备配置；F 位置合集仍保留该次实验的 episode 映射。
- 本机 LeRobot 为 editable 安装，包版本号不能替代源码提交及修改记录。
- 通用执行入口已提供并做离线参数验证，未在此次修改中运行机械臂；训练入口、数据模型下载和完整评估协议仍待补齐。
